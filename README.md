## Descripción del Proyecto
Este proyecto consiste en el desarrollo técnico de un sitio web estático completo para una agencia de turismo ficticia especializada en la promoción del cantón Ambato. El portal web está estructurado bajo principios de diseño semántico y modular, ofreciendo una experiencia interactiva para guiar al usuario a través de los atractivos históricos de la "Cuna de los Tres Juanes", sus masivos pulmones verdes, su riqueza culinaria y su emblemática festividad mayor.

El sitio web está compuesto por 5 páginas de contenidos unificadas de forma consistente:
1. **Inicio (`index.html`):** Presentación de la identidad visual de la agencia, sección hero adaptada, eslogan y muestra de atractivos destacados.
2. **Lugares Turísticos (`destinos.html`):** Catálogo de 6 atractivos turísticos principales estructurados con tarjetas que detallan su ubicación, descripción y actividades recomendadas con iconos personalizados.
3. **Servicios (`servicios.html`):** Oferta modular de 4 paquetes turísticos con descripciones extensas y tarifas referenciales de mercado.
4. **Nosotros (`nosotros.html`):** Reseña histórica de la agencia, pilares corporativos (Misión, Visión, Valores) alineados horizontalmente y razones de peso para visitar Ambato.
5. **Contacto / Reserva (`contacto.html`):** Formulario avanzado con controles HTML5 y validaciones nativas para solicitudes de reserva.

## Tecnologías Utilizadas
* **HTML5:** Estructuración semántica avanzada mediante el uso riguroso de etiquetas como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* **CSS3 Nativo:** Maquetación comercial externa implementando el modelo de caja (Box Model), layouts bidimensionales con **CSS Grid**, sistemas de alineación unidimensionales con **Flexbox**, pseudo-clases dinámicas (`:hover` y `:focus`) y variables globales para la estilización unificada de la paleta de colores de la provincia.
* **Diseño Responsive:** Adaptabilidad móvil de vanguardia sin desbordamiento horizontal mediante el uso estricto de Media Queries (`@media`).
* **Git & GitHub:** Sistema de control de versiones distribuido bajo una estrategia ordenada de commits.
* **GitHub Pages:** Infraestructura en la nube utilizada para el despliegue del entorno estático de producción.
